# Ready-to-use teams

These eight archives were supplied in `Team.zip` by the repository owner.
The original inner ZIPs are preserved byte for byte. Large ZIPs are stored as
ordered `.partNN` files; `presets.archive_bytes` reconstructs them and checks
the SHA-256 before use. `catalog.json` records the folder and launch command.

The website offers each team on either side, alongside personal ZIP upload.
It uses `localStartAll` when present, otherwise `start.sh`. Selecting a preset
fills and locks its name, working directory and command. Match execution,
private result storage and replay downloads use the existing Arena runner.

Including a team does not certify that its binaries run correctly or support
synchronous mode. The teams retain their original authors' licenses; inclusion
here does not relicense their contents under Arena's license.
